ERA Help

ERA provides an educational resource to support better understanding of the current state of research into epigenetic reprogramming and its effects on aging. It may also provide useful summaries and links to relevant published evidence for the clinical and biological relevance of specific interventions.

For more on ERA's data model and how it adapts CIViC's, see the project README.

ERA provides an open forum for community contributions. Anyone can create an account to flag problems, add comments, propose revisions to existing content, or submit new evidence, assertions, or summaries. All proposed additions/revisions enter a pending state until considered for acceptance by an ERA editor. All content contributed and accepted is immediately considered public domain knowledge.

For more details on how to contribute, see the Contributing section of the README.

We also provide a curation help chatbot that is able to answer questions about the ERA data model and curation SOP.

ERA data can be retrieved using the underlying GraphQL API. The schema is defined in code in the GitHub repository.

The GraphiQL user interface found here is a good way to get started interacting with the API. You can explore the schema and available queries using the "Docs" explorer found in the upper right.

ERA is in early development and we haven't recorded any tutorial videos yet. In the meantime, the GitHub repository and this Help page are the best places to start.
